How to use Evade.

Everything you need after installing: the launcher, the menu, keybinds, chat commands and the tools that need a little explaining.

The Evade Launcher

The Evade Launcher installs Evade and keeps it up to date. Press Play on its Home page: if Evade, Fabric or one of the extras has a new version it updates them first, then it opens the official Minecraft Launcher with the right profile already selected. Press Play there. Signing in stays with the Minecraft Launcher and your Microsoft account; the Evade Launcher never asks for your password. Home also has your servers (they're added to the Multiplayer list in game too), the latest news, which versions you have and Evade Clips. Evade Clips is built into the launcher: open it from Clips in the sidebar. Closing the window while instant replay is on keeps it running in the tray (right-click the tray icon to save a clip or quit).

Instances are separate setups, each with its own mods, settings, worlds and memory, and its own profile in the Minecraft Launcher (Evade Client — PvP, for example). Your first one is Main in .minecraft/evade; new ones go in .minecraft/evade-instances. Create, rename, duplicate or delete them, switch FPS mods, Shaders and Voice chat per instance, and copy game settings from another instance or your normal game. Changes are applied the next time you press Play.

Mods lists the mods in an instance. Switch your own mods off and on (the file is renamed to .jar.disabled, so nothing is lost) or remove them, and use Browse Modrinth to add Fabric mods for 1.21.11: the newest compatible version is installed with the libraries it needs, each checked against Modrinth's SHA-512. Evade, Fabric API and the extras are managed by Play and the instance's switches.

New instance offers templates: Blank (the usual Evade setup), PvP (lean) (FPS mods and faster start-up, nothing else), Survival + shaders (shaders, dynamic lights, voice chat and Open to Friends), Building (adds Litematica by masa for schematics) and Low-end laptop (the lightest setup, with memory sized for shared graphics). Everything a template sets can be changed later. Instances can be put in folders, pinned and sorted, exported as a .zip (with or without worlds) to move to another PC, and imported again. Import from another launcher finds Minecraft 1.21 instances in the usual launcher folders, without changing anything there, and copies game settings, keybinds, the server list, packs and (if you choose) worlds; mods are fetched again from Modrinth as their 1.21.11 Fabric build. A desktop shortcut starts an instance in one click.

Optional extras per instance, all off by default and downloaded from Modrinth when you switch them on: Faster start-up (Lazy Language Loader), More FPS (Particle Core and Entity View Distance), Singleplayer chunk speed, experimental (C2ME and ScalableLux) and Open to Friends (e4mc).

Memory: on a laptop whose only graphics are built into the processor, the graphics share your RAM, so the launcher recommends 3–4 GB and warns when an instance is given more than half your RAM. On PCs with RAM to spare, the Game page's settings offer a ZGC preset for steadier frame times.

Settings has the Minecraft folder, the memory for new instances, an optional Java path, whether the launcher closes when you press Play, update checks, a light theme, accent colours, larger text and reduce motion, and buttons to open each folder. The whole launcher works from the keyboard: press F1 for the shortcuts.

Game page, logs & crash help

The launcher stays open after Play and shows when you're playing, your play time per instance and a Stop button for a game that hangs. Click an instance's Game page for its status, play time and settings: memory, Java, window size and icon.

Logs follows the game's log live. Filter it to warnings or errors, search it, or open older logs. Share log copies it with what shouldn't leave your PC hidden first: sign-in tokens and session IDs, IP addresses, your Windows or Linux user name in file paths, and your Minecraft name.

Crash help: when a game ends badly, the launcher reads the crash report (or the end of the log) and says what probably happened in plain words, with a one-click fix where there is one: switch off the mod that crashed, give the game more (or less) memory, update the graphics driver, use the Minecraft Launcher's own Java, or open the report. Start in safe mode starts the game with every Evade mod off; see Safe Start.

Mods, packs & worlds

An instance's Mods page has four tabs:

  • Installed — your mods, resource packs and shader packs, with search, sort and where each came from (Evade, Modrinth or added by hand). Update chips show newer versions on Modrinth and Update all installs them; Evade's own files are never touched. Click a mod's version to pick any build for 1.21.11 with its changelog. Pin a mod to keep it where it is (Update all skips it), and Undo last update puts the previous files back. A check warns about missing libraries, mods that don't work together and two mods doing the same job, and one switch turns off every non-Evade mod to find a troublemaker (with Restore).
  • Browse Modrinth — mods, resource packs, shaders, data packs (into a world you choose) and modpacks, each with what it needs.
  • Worlds — back up a world to a zip (the newest backups are kept), restore, duplicate, rename, delete to the Recycle Bin, copy the seed, and manage its data packs. Nothing is changed while the game has the world open.
  • Modpacks & sharing — import a Modrinth .mrpack (Fabric 1.21.11) or an instance code (they start with EVI1-) into a new instance, or export this one. Instance codes list Modrinth projects, never files.

Drag and drop a file onto the launcher window: a Fabric mod goes into mods, a resource or shader pack into its folder, and a .mrpack or exported instance zip becomes a new instance. Each file is checked first (a Forge mod or one for another Minecraft version is refused with the reason) and looked up on Modrinth so it gets update checks too.

Safe Start

A broken setting or a clash with another mod should never lock you out of the game. If two starts in a row stop before the title screen, the next start comes up with every Evade mod off. The same happens once when you click Start in safe mode in the Evade Launcher (a request older than ten minutes is ignored).

On the title screen, Safe Start lists the mods that were on and, when the crash report names one, the suspect. Turn them back on one at a time, playing a little after each, to find the one that breaks; Turn all back on restores everything, and Keep them off closes the list. Nothing comes back on without your click.

While you play, an error inside one Evade mod switches off only that mod with a "Turned off after an error" message, instead of crashing the game. Turn it back on from the menu once you've changed the setting that caused it.

The menu

Press Right Shift in game. The sidebar has 5 categories plus All Mods, Edit HUD Layout, Profiles and Settings.

  • Left-click a card to turn the mod on or off.
  • Right-click a card, or click its gear, to open its settings.
  • Start typing anywhere to search all 113 mods.
  • On a mod's settings page, click Toggle Key and press a key to bind it. Esc cancels; right-click, Delete or Backspace clears a key. Keys a mod uses while it's on, like Zoom Key or Freelook Key, are separate settings on the same page and bind the same way.
  • Middle-click a setting to put it back to its default, or click Reset to put the whole mod back.

Every setting and its default is listed on the features page: open any mod to see them.

Three menu styles. Under Settings → GUI Style you can switch between List (the default: spacious full-width rows with a description, keybind chip and settings), Cards (a grid of cards) and Compact (a dense single-column list). The All / Enabled filter at the top right shows either every module or only the ones you have on. The controls are the same in all three.

Keybinds page

Open Keybinds in the menu's sidebar to see every key in one place: each mod's toggle key, the keys mods use while they're on, and the game's own controls, grouped and searchable. Keys used twice are shown in red. Click a key and press the new one; hold Ctrl, Shift or Alt with it to make a combo, so Ctrl+K and plain K can do different things. Right-click clears a key and Reset puts one back. A mod's key can Toggle it or work while you Hold it.

Pin the mods you use most to keep them at the top of the menu, and share one mod's settings as a code from its settings page.

Themes & accent colours

Open the menu's Settings page to restyle Evade. Changes show up instantly and restyle the menu and HUD together.

  • Theme — Modern (the default dark glass), Midnight (deep navy), OLED (true black) or Classic (vanilla-style grey with square corners).
  • Accent Color — Red, Blue, Purple, Pink, Orange, Gold, Green or Cyan. It colours switches, highlights, the HUD's top edges and the HUD editor's guides.
  • GUI Style — List, Cards or Compact. See all three on the showcase.
  • Smooth Font — the menu's clean Inter typeface (on), or the game's own pixel font (off).
  • Press Ctrl+F anywhere in the menu to search. Search matches mod names, descriptions and setting names.

Your theme is saved with your settings, so each profile can have its own look.

Profiles

Open Profiles in the menu to keep separate setups for different games. Each profile remembers its own enabled mods, every setting, your keybinds and your HUD layout.

  • Type a name and click Create to save your current setup as a new profile.
  • Click Use on any profile to switch to it — your current profile is saved first, so nothing is lost.
  • The × deletes a profile (you can't delete the active one or your last one).
  • Copy code puts a share code for that profile on your clipboard. A friend clicks Import to add it as a new profile.
  • On a server, Use on this server links the profile to it: Evade switches to it automatically every time you join.

Profiles live in config/evade/profiles/, one .json each.

Performance

Evade's Performance mod (Controls) is on by default. It skips drawing mobs and block entities past a distance you choose, draws one item per dropped stack, thins particles, idles at a low frame rate when you tab out or go AFK (back to full speed the moment you move) and can apply lighter video settings — all restored when you turn it off. On a weak PC, switch on Low-End PC Mode too: solid leaves, smooth lighting off, no chunk fade-in, biome blend off and a shorter entity distance.

FPS Mode sets everything in one click: Max FPS (render distance up to 8, Low-End PC Mode on), Balanced (the default: render distance up to 12, smooth lighting kept) or Quality (only unlocks the frame rate). Pick Custom to set each option yourself. Unlock FPS turns VSync off and sets Max Framerate to Unlimited the first time you play (you'll see a notification); turn it off to put your own back. Type .bench (or .bench 60) to measure average FPS and the 1% low; each run is compared with the last and saved to config/evade/bench.txt.

Shaders switches Iris between Off, Evade Shaders (our own pack, free with Evade Client), Photon (by SixthSurge, the best looking) and Complementary Reimagined (lighter, for laptops) without opening Iris' menus. They're added when you switch on Shaders in the Evade Launcher: Evade Shaders from evadeclient.com, the others from Modrinth. With built-in graphics, Evade Shaders starts on its Low level until you change its settings.

Its Effects settings cut the eye candy that costs frames:

  • Particle Distance (32 blocks): particles further away aren't created at all.
  • Hide Ambient Particles (on): campfire smoke, ash, spores, falling leaves, water drips and fireflies.
  • Hide Lava Drips (off): lava dripping through a ceiling warns you there's lava above, so it stays visible unless you switch this on.
  • Less Block Break Dust (on): a quarter of the dust when blocks break, which adds up fast when mining or when TNT goes off.
  • Hide Rain Splashes (on): the splashes raindrops make on the ground, plus a shorter weather radius with Lighter Video Settings. Splashes from things landing in water still show.
  • Hide Fire On Mobs (on): burning mobs skip their fire layer. Burning players still show it.
  • Hide Rain & Snow (off): skips drawing precipitation completely, for the weakest PCs.

Particles that tell you something, like a fishing bite, a splash, bubbles or an explosion, are never thinned or cut by distance. For the fire on your own screen, Pack Tweaks lowers it and NoRender hides it.

Shaders: switch on Shaders for an instance in the Evade Launcher to add Iris from Modrinth: real-time shadows, volumetric light, reflective water and more. Packs on the Shaders row picks the shader packs that come with it: Evade Shaders, our own pack and free with Evade Client (Potato to Ultra levels in its settings; it's the one switched on first), Photon by SixthSurge (high-end) and Complementary Reimagined by EminGT (lighter) are ticked by default; Complementary Unbound by EminGT (realistic), BSL by CaptTatsu (warm, mid-range) and Sildur’s Vibrant by Sildur (runs on almost anything) are there to tick. Evade Shaders downloads from evadeclient.com and the others from Modrinth when you press Play (Evade never hosts them), unticking a pack removes it again, and packs you added yourself are never touched. On a PC with built-in graphics the launcher suggests Evade Shaders and Complementary Reimagined. From the command line: --shader-packs evade-shaders,photon,complementary-reimagined,complementary-unbound,bsl,sildurs-vibrant. Shaders cost a lot of FPS, so they're off by default. Press K in game to turn them on or off, or click Shaders Now under Performance to pick any pack in your shaderpacks folder (the Mod Browser's Shaders tab finds more on Modrinth).

Resource pack features: many resource packs use extra formats for connected glass and bookshelves, renamed-item textures, random mob skins, custom mob models and custom skies. With Resource pack features on (the default) the Evade Launcher adds the mods that read them from Modrinth: Continuity (connected and emissive textures), CIT Resewn Continuation (custom item textures), Entity Texture Features and Entity Model Features (random and emissive entity textures, custom entity models) and Skyboxify (custom skies, with its library YetAnotherConfigLib). Dynamic lights (off by default) adds LambDynamicLights. In the resource pack screen, the ? button next to the search box lists what each of your packs needs and whether it's installed.

Benchmark Every FPS Mode (or .bench all) measures Max FPS, Balanced and Quality in turn and recommends the best-looking one that keeps up with your monitor. Borderless Fullscreen fills the screen with a frameless window for instant Alt-Tab.

Memory: the Evade Launcher recommends how much memory to give Minecraft based on your PC. More isn't faster: an oversized heap makes garbage-collection pauses longer.

The Evade Launcher also adds Sodium, Lithium, FerriteCore, ImmediatelyFast, EntityCulling, MoreCulling (with its library, Cloth Config), Krypton, BadOptimizations and Sodium Extra, plus Fast IP Ping and FastQuit for a quicker server list and instant world quitting from Modrinth (leave FPS mods on). They stack with Evade's own mod; the FPS Mods Installed line in Performance's settings shows which are loaded. It also sets low-pause memory settings for smoother frame times.

Render Scale (Performance) draws the world at a lower resolution and sharpens it, while the HUD, menus and text stay crisp: the biggest single gain in fullscreen on a laptop. Balanced uses 80% and Max FPS 60%. The first-run setup's Tune for my PC measures your frame rate for 10 seconds and picks an FPS Mode for your hardware; type .setup to run the setup again.

Measure it yourself. We don't publish FPS numbers we haven't measured on your kind of PC, so Evade gives you the tools: .bench for average FPS and 1% lows, Benchmark Every FPS Mode to compare modes on your own PC, and the two widgets below. Each run is saved, so you can see what a change really did.

Turn on the Frame Time Graph (HUD) to see how smooth your game really is: one bar per frame (green inside a 60 FPS budget, yellow slower, red for stutters), plus your average FPS, your 1% low (the FPS of your slowest frames, which is what you feel) and your worst frame.

Voice chat

Evade's voice chat is Simple Voice Chat by henkelmax. The Evade Launcher downloads it straight from Modrinth when you leave Voice chat switched on.

  • It works on every server that runs Simple Voice Chat, and in singleplayer and LAN worlds you host.
  • Press V (or type .voice, or click Voice Chat in the menu) for its menu. The first time, its setup guide walks you through your mic and push-to-talk key.
  • On macOS, allow microphone access for Minecraft / Java the first time you talk.

Evade icons

Players on Evade show the Evade logo before their name in the tab list. Every Evade player gets it, for free. Settings are under Evade Icons (Misc):

  • Show Icons — show icons next to other players.
  • Show That I Use Evade — let others see your icon. Switch it off and your icon is taken down straight away, and Evade stops reporting that you're online.

Your icon is verified with the chat-signing key Mojang gives every Microsoft account (the one servers use to check signed chat), so it can't be faked. Evade only learns your player ID; your password, login token and username never reach us. Icons need a Microsoft account; offline or cracked accounts don't get one. What is sent and kept is in the privacy policy.

Friends & parties

Click your name at the bottom of the menu's sidebar to open Friends, then Turn on Friends. Nothing is sent to us until you do. Evade checks your Minecraft account the same way as for Evade icons, so friends need a Microsoft account and Evade too.

  • Friends — type a friend's Minecraft name and click Add. Evade asks Mojang which account has that name, so a request always goes to the right player. Your friends list shows who's online and, if they share it, which server they're on. Up to 300 friends.
  • Requests — accept, decline or block friend requests, and join or decline party invites. Invites lapse after 10 minutes.
  • Party — invite online friends (up to 8 players). The leader can make someone else leader or remove a member. A party with nobody online for 12 hours ends.
  • Settings — Allow friend requests, Share my server with friends (on by default), toasts, Party Ping, your blocked players and Delete my social data.

Party Ping (Misc): in a party, press the middle mouse button to mark the block, mob or player you're looking at, up to 256 blocks away; hold Sneak for a danger ping. Party members on the same server see a marker with your name, distance and coordinates for 10 seconds, a toast, a sound and a dot on their minimap. Nobody else gets it, and pings aren't stored. Out of a party the button does nothing extra, and in creative it still picks the block you look at within reach (switch off Keep Pick Block In Creative, or bind Ping Key to a side button). Pings only work on public multiplayer servers, never in singleplayer or on a LAN address, and a server can switch Party Ping off for its players.

Clips

Turn on Clips (Misc) to keep your best moments; it's already on if you use the Evade Launcher, which has Evade Clips built in. Its Recorder setting picks where clips go:

  • Auto (the default): Evade Clips whenever the app is running, the built-in recorder otherwise.
  • Evade Clips: clips go to the app, with sound, where you can edit them and share links that play in Discord. See Evade Clips.
  • Built-in: Evade keeps the last 10–120 seconds of your screen in memory and saves them as an MP4 in .minecraft/evade/clips, at 480p, 720p or 1080p and 15–60 FPS. These clips are video only, with no sound: for sound, keep Evade Clips running.

Press F8 or type .clip (or .clips save) to save a clip; .clips opens Evade Clips and .clips last opens your newest clip in its editor. Evade also clips by itself with either recorder: your kills (close ones become one “Double kill” or “Triple kill” clip), totem pops of players you're fighting, wins and advancements are on by default, and deaths are off. Seconds After sets how long it keeps recording after the moment, and in Evade Clips each one gets a named marker on the timeline. Bind Open Clips App to open the app from in game.

Evade Clips works only with Evade Client: it records the Minecraft window while Minecraft with Evade Client is open, and only accepts clips from Evade Client. Windows records the monitor Minecraft is on with Desktop Duplication (or the Minecraft window itself if that isn't available), Linux the window's area of the X11 screen, and macOS the main screen. In Evade Clips, F8 saves, F9 starts or stops a recording and F7 drops a marker; with voice commands on, say “clip that” (or “clip it”, “save clip”, “save that”), “start recording”, “stop recording” or “mark that”.

Session recap (the library's toolbar) makes one captioned video from the day's auto-clips, landscape or vertical. Replays you render from 3D Replay go to the Evade Clips library; Queue render on the Replays screen renders several one after another, each with a share link if you choose. Shared clips get 25 GB of free storage per PC; when it's full, new shares wait until you stop sharing older ones.

Server-safe recording: Clips only records what's already on your screen. Servers can switch off the Clips mod like any Evade mod: auto-clips and the built-in recorder stop there (its buffer is dropped), and clips you've already saved stay on your PC.

Replay

Replay (Misc) records the world in 3D as you play: blocks, players, mobs, items, effects and sounds. Afterwards you fly through it with a free camera, make camera paths and render them as video. It's on by default and keeps the current session ready, so Start recording in the pause menu (or the Start / Save Key, or .replay) works mid-match too; Record Every Session records everything. Add markers for the moments you want with the Marker Key or .replay marker <name>.

  • Open saved replays from the Replays button on the title screen.
  • In a replay, close the editor (E) to fly, and press K to add a camera keyframe where you are. Move on in time, fly somewhere else, press K again: that's a camera path.
  • Camera: keyframes with field of view and roll, look at or orbit a player or mob, and speed keyframes for slow motion and time-lapse. Scene: time of day, weather, fog, name tags, hiding players or mobs, and a green screen. Render: resolution, frame rate and quality, then render to an MP4 with the game's sound.
  • With Simple Voice Chat, Record Voice Chat keeps what players near you said, played back from where they stood. Switch off Record My Voice to leave yours out.

A replay only holds what your own game received while you played, so it shows nothing you couldn't see at the time.

Streamer Mode

Switch on Streamer Mode (Misc) before you go live. It keeps private details off your screen:

  • Hide Coordinates — the Coordinates widget, waypoint labels and shared waypoints leave out where you are.
  • Hide Server Address — the Server widget shows the server's name from your list instead of its address.
  • Turn On Nick Hider — your name is replaced on screen (and Nick Hider goes back off afterwards if it was off).
  • Hide Friend Servers — friends' servers and message previews are hidden in the friends list and toasts.
  • Indicator — a small Streamer tag in the top-right corner, so you know it's on.

HUD editor

Open the menu and click Edit HUD Layout. Drag elements to move them; they snap to edges and to each other. Scroll over an element to resize it, and right-click it for its settings. Press G to snap to a grid instead.

Every HUD element can be styled on its own:

  • Background Style — Evade (dark glass with an accent edge), Solid, Glass or Outline, plus Background Opacity. Switch Background off for none.
  • Text elements: Text Color, Text Shadow, Chroma (a flowing rainbow), Smooth Font and Brackets.
  • Hide In Menus hides it while a menu is open; Only In Combat shows it only for a few seconds after you hit something or take damage.

Stacks: pick two or more widgets (Shift+click or drag a box) and click Stack. They then move together and sit one under another with a small gap, closing up when one of them has nothing to show. A stack hangs from its top widget, or grows upwards when its bottom widget sits against the bottom of the screen. Click any widget in a stack to pick the whole stack (Shift+click picks one on its own); Unstack separates them. Stacks are saved with your config and profiles.

The Frame Profiler element shows where your frame time goes: FPS and 1% low, average and worst frame time, how long Evade's HUD takes, and garbage-collection pauses (the usual cause of micro-stutter).

The editor also has undo and redo (Ctrl+Z / Ctrl+Y), arrow keys to nudge, align buttons for several widgets, locks, right-click on empty space to add a widget, ready-made layouts, and HUD codes to share your layout.

Custom Text

The three Custom Text widgets show your own text with live values. Type the values in curly brackets:

{fps} · {ping} · {cps} · {rcps}Frame rate, your ping, left and right clicks per second
{x} {y} {z} · {nether_x} {nether_z}Your position, and where it lands in the Nether (or the Overworld)
{biome} · {dimension} · {facing} · {facing_short} · {yaw} · {pitch}Where you are and which way you look
{time} · {time:HH:mm} · {day}Your clock (any format) and the in-game day
{health} · {food} · {armor} · {level} · {speed}Your own health, hunger, armour points, XP level and speed in blocks per second
{held} · {durability} · {count:totem_of_undying}The item in your hand, its durability, and how many of an item you carry
{mod:Zoom} · {server} · {username}Whether a mod is on, the server you're on, your name
{memory} · {memory_used} · {memory_max}Minecraft's memory use

Colours: <red>, <#FF8800> or <accent> colour the text that follows, </> goes back to the colour before and <reset> to the widget's own. Conditions: {if ping>150}High ping{else}OK{end} (also < >= <= = !=, and {if mod:Zoom} for "is on"). \n starts a new line. Every value is something the game already shows you about yourself; coordinates and the biome follow the server's Reduced Debug Info rule, like the Coordinates widget.

Waypoints & World Map

Waypoints are on by default. .waypoint add Base saves where you stand; it shows as a beam with its name and distance. They're saved per server (or singleplayer world) and per dimension. When you die, a Death waypoint is added automatically; turn that off in the Waypoints settings.

The Waypoint Manager (Waypoints settings, the World Map's Waypoints button, or .wp gui) lists this world's points nearest first, or by name or age, with search. Change a point's name, colour, icon, beam and how far away it still shows; hide it, make it your target, delete it (with Undo), or put its coordinates in the chat box to send yourself. Nothing teleports and nothing is sent for you.

The World Map (Visuals, on by default) opens with J or .map: a full-screen map of the ground you've explored, saved per server and world and shared with the Minimap. Drag to move, scroll to zoom, click to add a waypoint, and right-click a waypoint to edit it, target it or delete it. It only shows surface terrain your game has actually loaded: nothing underground, no other players, and no coordinates where a server hides them from F3. Memory Limit caps how much map stays in memory; older areas are saved and reloaded when you look at them.

Item View & Damage Numbers

Item View (Visuals) moves, tilts, turns and resizes the item in each hand, changes how fast the swing animation looks (attack timing is untouched), and can hide your shield when you aren't blocking. 1.7 Animations brings back the old sword-block pose, red armour when hurt, the old hurt tilt, sneak camera and heart flash.

Damage Numbers (Visuals) shows a floating number, or a hit marker, on things you hit, and only once the server confirms the hit was yours. It never shows anyone's health.

Open Screenshots in the menu (or type .shots) to browse this game folder's screenshots. Copy one to the clipboard, rename it, show it in its folder or delete it; deleted ones go to screenshots/.trash for a week, and Undo (Ctrl+Z) brings one back.

For mod developers

Other client-side Fabric mods can add their own modules, settings and HUD widgets to Evade with the Evade Addon API (package net.evadeclient.addon). They show up in the menu with an Addon: <your mod> tag, in search, keybinds, profiles, .toggle and .set, and widgets appear in the HUD editor. Their settings are saved in Evade's config. This is separate from the Server API, which is for Minecraft servers.

Compile against the Evade jar without bundling it (for example modCompileOnly files("libs/evade-client.jar")), then list an entrypoint called evade in your fabric.mod.json:

"entrypoints": { "evade": ["com.example.MyEvadeAddon"] },
"suggests": { "evade": "*" }
public final class MyEvadeAddon implements EvadeAddon {
    @Override
    public void register(AddonRegistry registry) {
        registry.module(new Greeter());
        registry.hud(new SessionTimer());
    }
}

public final class Greeter extends AddonModule {
    final BooleanSetting loud = toggle("Loud", false, "Say it in capitals.");
    final NumberSetting times = slider("Times", 1, 1, 5, 1, "How many times to say it.");
    final ModeSetting style = mode("Style", "Friendly", "How it sounds.", "Friendly", "Formal");
    final ColorSetting tint = color("Tint", 0xFF3BE37A, "Colour of the greeting.");
    final KeySetting greetKey = key("Greet Key", GLFW.GLFW_KEY_UNKNOWN, "Hold to greet.");
    final StringSetting greeting = text("Greeting", "Hello", 32, "What it says.");

    public Greeter() { super("Greeter", "Says hello when you join a world.", AddonCategory.MISC); }

    @Override protected void onEnable() { /* ... */ }
}

public final class SessionTimer extends AddonTextHud {
    private final long start = System.currentTimeMillis();
    public SessionTimer() { super("Session Timer", "How long you've been playing.", 4, 60); }

    @Override protected List<String> lines(boolean preview) {
        return List.of("Session: " + (System.currentTimeMillis() - start) / 60000 + " min");
    }
}
  • Modules extend AddonModule and get the usual hooks: onTick, onRender, onHud, onEnable/onDisable and chat commands. They start off.
  • Widgets extend AddonTextHud (lines of text, styled like Evade's own) or AddonHudElement (draw anything; call size(w, h)). Both get Scale, Background, Hide In Menus and the other widget settings.
  • Settings: toggle, slider, mode, color, key and text. Keep module and setting names stable: saved values are keyed by them. A name that clashes with another module is refused.
  • Server rules apply. Servers can switch addon modules off with evade:rules by name, all of them with "@addons", or one mod's with "@addon:<modid>". Addons can't turn a module on past that. A module that throws an error is switched off.

Your addon is your responsibility. Evade can't review other mods' code, so it always shows which mod added each module. Please keep to Evade's own rules: nothing that shows what the game hides, and no automation of combat, movement or inventory. Servers may ban mods that do.
