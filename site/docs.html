How to use Evade.

Everything you need after installing: the menu, keybinds, chat commands and the tools that need a little explaining.

The menu Default keys Chat commands HUD editor Printer Waypoints Testing with FakePlayer Config files

The menu

Press Right Shift in game. The sidebar has 8 categories plus All Mods, Edit HUD Layout and Settings.

  • Left-click a card to turn the mod on or off.
  • Right-click a card, or click its gear, to open its settings.
  • Start typing anywhere to search all 129 mods.
  • On a settings page, click Keybind and press a key to bind it. Right-click, Esc, Delete or Backspace clears it.

Every setting and its default is listed on the features page: open any mod to see them.

Three menu styles. Under Settings → GUI Style you can switch between Cards (the default), Compact (a dense single-column list) and Doomsday (a two-column terminal-style list). The controls are the same in all three.

Default keys

Right ShiftOpen the menu (change it under Settings)
CZoom (scroll while zooming to change how far)
Left AltFreelook
Middle mouseThrow a pearl, with MiddleClickExtra on

Every other mod starts unbound. Bind the ones you use most from their settings page or with .bind.

Chat commands

Commands start with a dot and are never sent to the server.

.helpList commands
.toggle <mod>Turn a mod on or off (short: .t)
.bind <mod> <key|none>Set or clear a keybind
.set <mod> <setting> <value>Change a setting, e.g. .set KillAura Range 4
.modulesList every mod, enabled ones in green
.printer list | load <name> | here | unload | materials | folder | infoSchematic printer
.waypoint add <name> | del <name> | list | clearWaypoints (short: .wp)
.save / .loadSave or reload your config

HUD editor

Open the menu and click Edit HUD Layout. Drag elements to move them; they snap to edges and to each other. Scroll over an element to resize it. Each of the 18 HUD elements also has its own scale, background and colour settings.

Printer

The Printer places the blocks of a schematic for you, bottom to top, with the right rotation, using blocks from your hotbar.

  1. With Litematica: place a schematic in Litematica as usual, then turn on the Printer.
  2. Without Litematica: put .litematic files in .minecraft/evade/schematics (or .minecraft/schematics). Type .printer list, then .printer load <name>. It's placed at your feet; .printer here moves it.
  3. Type .printer materials to see which blocks you still need.

Need Litematica and its library? The Printer add-ons section links to the right versions (Litematica 0.26.16, MaLiLib 0.27.20) in one place.

Waypoints

Waypoints are on by default. .waypoint add Base saves where you stand; it shows as a red beam with its name and distance. They're saved per server (or singleplayer world) and per dimension. When you die, a Death waypoint is added automatically; turn that off in the Waypoints settings.

Testing with FakePlayer

Turn on FakePlayer to spawn a copy of yourself that only you can see. KillAura, CrystalAura, ESP, Nametags and the other player modules treat it like a real player, so you can set them up in singleplayer. The server doesn't know it exists, so hits on it do nothing. Turning FakePlayer off removes it.

Config files

.minecraft/evade/config/evade/config.jsonMods, settings, keybinds, HUD layout
.minecraft/evade/config/evade/waypoints.jsonWaypoints
.minecraft/evade/schematics/Schematics for the Printer

Paths are for an installer setup. If you dropped the jar into your own Fabric install, they're inside that instance's folder instead.
