How to use Evade.

Everything you need after installing: the launcher, the menu, keybinds, chat commands and the tools that need a little explaining.

The Evade Launcher

The Evade Launcher installs Evade and keeps it up to date. Press Play on its Home page: if Evade, Fabric or one of the extras has a new version it updates them first, then it opens the official Minecraft Launcher with the right profile already selected. Press Play there. Signing in stays with the Minecraft Launcher and your Microsoft account; the Evade Launcher never asks for your password. Home also has your servers (they're added to the Multiplayer list in game too), the latest news, which versions you have and Evade Clips. Evade Clips is built into the launcher: open it from Clips in the sidebar. Closing the window while instant replay is on keeps it running in the tray (right-click the tray icon to save a clip or quit).

Instances are separate setups, each with its own mods, settings, worlds and memory, and its own profile in the Minecraft Launcher (Evade Client — PvP, for example). Your first one is Main in .minecraft/evade; new ones go in .minecraft/evade-instances. Create, rename, duplicate or delete them, switch FPS mods, Shaders and Voice chat per instance, and copy game settings from another instance or your normal game. Changes are applied the next time you press Play.

Mods lists the mods in an instance. Switch your own mods off and on (the file is renamed to .jar.disabled, so nothing is lost) or remove them, and use Browse Modrinth to add Fabric mods for 1.21.11: the newest compatible version is installed with the libraries it needs, each checked against Modrinth's SHA-512. Evade, Fabric API and the extras are managed by Play and the instance's switches.

Settings has the Minecraft folder, the memory for new instances, an optional Java path, whether the launcher closes when you press Play, update checks, and buttons to open each folder.

The menu

Press Right Shift in game. The sidebar has 5 categories plus All Mods, Edit HUD Layout, Profiles and Settings.

  • Left-click a card to turn the mod on or off.
  • Right-click a card, or click its gear, to open its settings.
  • Start typing anywhere to search all 97 mods.
  • On a mod's settings page, click Toggle Key and press a key to bind it. Esc cancels; right-click, Delete or Backspace clears a key. Keys a mod uses while it's on, like Zoom Key or Freelook Key, are separate settings on the same page and bind the same way.
  • Middle-click a setting to put it back to its default, or click Reset to put the whole mod back.

Every setting and its default is listed on the features page: open any mod to see them.

Three menu styles. Under Settings → GUI Style you can switch between List (the default: spacious full-width rows with a description, keybind chip and settings), Cards (a grid of cards) and Compact (a dense single-column list). The All / Enabled filter at the top right shows either every module or only the ones you have on. The controls are the same in all three.

Themes & accent colours

Open the menu's Settings page to restyle Evade. Changes show up instantly and restyle the menu and HUD together.

  • Theme — Modern (the default dark glass), Midnight (deep navy), OLED (true black) or Classic (vanilla-style grey with square corners).
  • Accent Color — Red, Blue, Purple, Pink, Orange, Gold, Green or Cyan. It colours switches, highlights, the HUD's top edges and the HUD editor's guides.
  • GUI Style — List, Cards or Compact. See all three on the showcase.
  • Smooth Font — the menu's clean Inter typeface (on), or the game's own pixel font (off).
  • Press Ctrl+F anywhere in the menu to search. Search matches mod names, descriptions and setting names.

Your theme is saved with your settings, so each profile can have its own look.

Profiles

Open Profiles in the menu to keep separate setups for different games. Each profile remembers its own enabled mods, every setting, your keybinds and your HUD layout.

  • Type a name and click Create to save your current setup as a new profile.
  • Click Use on any profile to switch to it — your current profile is saved first, so nothing is lost.
  • The × deletes a profile (you can't delete the active one or your last one).
  • Copy code puts a share code for that profile on your clipboard. A friend clicks Import to add it as a new profile.
  • On a server, Use on this server links the profile to it: Evade switches to it automatically every time you join.

Profiles live in config/evade/profiles/, one .json each.

Performance

Evade's Performance mod (Controls) is on by default. It skips drawing mobs and block entities past a distance you choose, draws one item per dropped stack, thins particles, idles at a low frame rate when you tab out or go AFK (back to full speed the moment you move) and can apply lighter video settings — all restored when you turn it off. On a weak PC, switch on Low-End PC Mode too: solid leaves, smooth lighting off, no chunk fade-in, biome blend off and a shorter entity distance.

FPS Mode sets everything in one click: Max FPS (render distance up to 8, Low-End PC Mode on), Balanced (the default: render distance up to 12, smooth lighting kept) or Quality (only unlocks the frame rate). Pick Custom to set each option yourself. Unlock FPS turns VSync off and sets Max Framerate to Unlimited the first time you play (you'll see a notification); turn it off to put your own back. Type .bench (or .bench 60) to measure average FPS and the 1% low; each run is compared with the last and saved to config/evade/bench.txt.

Shaders switches Iris between Off, Photon (by SixthSurge, the best looking) and Complementary Reimagined (lighter, for laptops) without opening Iris' menus. Both packs come from Modrinth when you switch on Shaders in the Evade Launcher.

Its Effects settings cut the eye candy that costs frames:

  • Particle Distance (32 blocks): particles further away aren't created at all.
  • Hide Ambient Particles (on): campfire smoke, ash, spores, falling leaves, water drips and fireflies.
  • Hide Lava Drips (off): lava dripping through a ceiling warns you there's lava above, so it stays visible unless you switch this on.
  • Less Block Break Dust (on): a quarter of the dust when blocks break, which adds up fast when mining or when TNT goes off.
  • Hide Rain Splashes (on): the splashes raindrops make on the ground, plus a shorter weather radius with Lighter Video Settings. Splashes from things landing in water still show.
  • Hide Fire On Mobs (on): burning mobs skip their fire layer. Burning players still show it.
  • Hide Rain & Snow (off): skips drawing precipitation completely, for the weakest PCs.

Particles that tell you something, like a fishing bite, a splash, bubbles or an explosion, are never thinned or cut by distance. For the fire on your own screen, Pack Tweaks lowers it and NoRender hides it.

Shaders: switch on Shaders for an instance in the Evade Launcher to add Iris with the Photon shader pack by SixthSurge, plus the lighter Complementary Reimagined, from Modrinth: real-time shadows, volumetric light, reflective water and more. Shaders cost a lot of FPS, so they're off by default. Press K in game to turn them on or off, or click Shaders Now under Performance to pick any pack in your shaderpacks folder (the Mod Browser's Shaders tab finds more on Modrinth).

Resource pack features: many resource packs use extra formats for connected glass and bookshelves, renamed-item textures, random mob skins, custom mob models and custom skies. With Resource pack features on (the default) the Evade Launcher adds the mods that read them from Modrinth: Continuity (connected and emissive textures), CIT Resewn Continuation (custom item textures), Entity Texture Features and Entity Model Features (random and emissive entity textures, custom entity models) and Skyboxify (custom skies, with its library YetAnotherConfigLib). Dynamic lights (off by default) adds LambDynamicLights. In the resource pack screen, the ? button next to the search box lists what each of your packs needs and whether it's installed.

Benchmark Every FPS Mode (or .bench all) measures Max FPS, Balanced and Quality in turn and recommends the best-looking one that keeps up with your monitor. Borderless Fullscreen fills the screen with a frameless window for instant Alt-Tab.

Memory: the Evade Launcher recommends how much memory to give Minecraft based on your PC. More isn't faster: an oversized heap makes garbage-collection pauses longer.

The Evade Launcher also adds Sodium, Lithium, FerriteCore, ImmediatelyFast, EntityCulling, MoreCulling (with its library, Cloth Config), Krypton, BadOptimizations and Sodium Extra, plus Fast IP Ping and FastQuit for a quicker server list and instant world quitting from Modrinth (leave FPS mods on). They stack with Evade's own mod; the FPS Mods Installed line in Performance's settings shows which are loaded. It also sets low-pause memory settings for smoother frame times.

Turn on the Frame Time Graph (HUD) to see how smooth your game really is: one bar per frame (green inside a 60 FPS budget, yellow slower, red for stutters), plus your average FPS, your 1% low (the FPS of your slowest frames, which is what you feel) and your worst frame.

Voice chat

Evade's voice chat is Simple Voice Chat by henkelmax. The Evade Launcher downloads it straight from Modrinth when you leave Voice chat switched on.

  • It works on every server that runs Simple Voice Chat, and in singleplayer and LAN worlds you host.
  • Press V (or type .voice, or click Voice Chat in the menu) for its menu. The first time, its setup guide walks you through your mic and push-to-talk key.
  • On macOS, allow microphone access for Minecraft / Java the first time you talk.

Evade icons

Players on Evade show the Evade logo before their name in the tab list. Every Evade player gets it, for free. Settings are under Evade Icons (Misc):

  • Show Icons — show icons next to other players.
  • Show That I Use Evade — let others see your icon. Switch it off and your icon is taken down straight away, and Evade stops reporting that you're online.

Your icon is verified through Mojang's sign-in check, the one servers already use, so it can't be faked. Evade only learns your username and player ID; your password and login token stay between you and Mojang. Icons need a Microsoft account; offline or cracked accounts don't get one.

Friends & parties

Click your name at the bottom of the menu's sidebar to open Friends, then Turn on Friends. Nothing is sent to us until you do. Evade checks your Minecraft account the same way as for Evade icons, so friends need a Microsoft account and Evade too.

  • Friends — type a friend's Minecraft name and click Add. Evade asks Mojang which account has that name, so a request always goes to the right player. Your friends list shows who's online and, if they share it, which server they're on. Up to 300 friends.
  • Requests — accept, decline or block friend requests, and join or decline party invites. Invites lapse after 10 minutes.
  • Party — invite online friends (up to 8 players). The leader can make someone else leader or remove a member. A party with nobody online for 12 hours ends.
  • Settings — Allow friend requests, Share my server with friends (on by default), toasts, Party Ping, your blocked players and Delete my social data.

Party Ping (Misc): in a party, press the middle mouse button to mark the block, mob or player you're looking at, up to 256 blocks away; hold Sneak for a danger ping. Party members on the same server see a marker with your name, distance and coordinates for 10 seconds, a toast, a sound and a dot on their minimap. Nobody else gets it, and pings aren't stored. Out of a party the button does nothing extra, and in creative it still picks the block you look at within reach (switch off Keep Pick Block In Creative, or bind Ping Key to a side button). Pings only work on public multiplayer servers, never in singleplayer or on a LAN address, and a server can switch Party Ping off for its players.

Clips

Turn on Clips (Misc) to keep your best moments; it's already on if you use the Evade Launcher, which has Evade Clips built in. Its Recorder setting picks where clips go:

  • Auto (the default): Evade Clips whenever the app is running, the built-in recorder otherwise.
  • Evade Clips: clips go to the app, with sound, where you can edit them and share links that play in Discord. See Evade Clips.
  • Built-in: Evade keeps the last 10–120 seconds of your screen in memory and saves them as an MP4 in .minecraft/evade/clips, at 480p, 720p or 1080p and 15–60 FPS. These clips are video only, with no sound.

Press F8 or type .clip to save a clip. Evade also clips by itself with either recorder: your kills, totem pops of players you're fighting, wins and advancements are on by default, and deaths are off. Seconds After sets how long it keeps recording after the moment, and in Evade Clips each one gets a named marker on the timeline. Bind Open Clips App to open the app from in game.

Evade Clips works only with Evade Client: it records the Minecraft window while Minecraft with Evade Client is open, and only accepts clips from Evade Client.

Chat commands

Commands start with a dot and are never sent to the server. Mod and setting names can be typed with or without spaces, in any case: .toggle NickHider and .toggle nick hider both work.

.helpList commands
.menuOpen the Evade menu
.toggle <mod>Turn a mod on or off; name several to switch them all (short: .t)
.bind <mod> <key|none>Set or clear a mod's toggle key. The middle and side mouse buttons work too, e.g. .bind Fullbright mouse4
.set <mod> <setting> <value>Change a setting, e.g. .set Zoom Level 4. Leave out the value to see the current one.
.modulesList every mod, enabled ones in green
.voiceOpen the voice chat menu
.clip or .clips saveSave a clip now
.clipsOpen Evade Clips, or the clips folder without it
.clips lastOpen your last clip in the Evade Clips editor
.nick <name>Set the name Nick Hider shows instead of yours
.waypoint add <name> | del <name> | list | clearWaypoints (short: .wp)
.friend add | remove | accept | decline | block | unblock <name>Friends; .friend list shows who's online, .friend requests what's waiting
.party invite | kick | leader <name>Your party; also .party accept, .party decline, .party leave, .party list and .party bring (leader: ask the party to join your server)
.msg <friend> <text> · .reply <text> · .pc <text>Message a friend, answer the last one who messaged you, or talk to your party. Sent through Evade, not the server; plain text, 256 characters
.join <friend>Join the server a friend is sharing (you confirm first)
.ping [danger|loot]Ping where you're looking, for your party on the same server
.shotsOpen the screenshot gallery
.saveSave your config now
.loadReload your config from disk

HUD editor

Open the menu and click Edit HUD Layout. Drag elements to move them; they snap to edges and to each other. Scroll over an element to resize it, and right-click it for its settings. Press G to snap to a grid instead.

Every HUD element can be styled on its own:

  • Background Style — Evade (dark glass with an accent edge), Solid, Glass or Outline, plus Background Opacity. Switch Background off for none.
  • Text elements: Text Color, Text Shadow, Chroma (a flowing rainbow), Smooth Font and Brackets.
  • Hide In Menus hides it while a menu is open; Only In Combat shows it only for a few seconds after you hit something or take damage.

Stacks: pick two or more widgets (Shift+click or drag a box) and click Stack. They then move together and sit one under another with a small gap, closing up when one of them has nothing to show. A stack hangs from its top widget, or grows upwards when its bottom widget sits against the bottom of the screen. Click any widget in a stack to pick the whole stack (Shift+click picks one on its own); Unstack separates them. Stacks are saved with your config and profiles.

The Frame Profiler element shows where your frame time goes: FPS and 1% low, average and worst frame time, how long Evade's HUD takes, and garbage-collection pauses (the usual cause of micro-stutter).

Waypoints

Waypoints are on by default. .waypoint add Base saves where you stand; it shows as a red beam with its name and distance. They're saved per server (or singleplayer world) and per dimension. When you die, a Death waypoint is added automatically; turn that off in the Waypoints settings.

Config files

Screenshots: open Screenshots in the menu (or type .shots) to browse this game folder's screenshots. Copy, rename, show in folder or delete them; deleted ones go to screenshots/.trash for a week, and Undo (Ctrl+Z) brings one back.

Paths are for the Evade Launcher's Main instance. Other instances keep theirs in .minecraft/evade-instances/<name>/config/evade. If you dropped the jar into your own Fabric install, they're inside that game folder instead.

For mod developers

Other client-side Fabric mods can add their own modules, settings and HUD widgets to Evade with the Evade Addon API (package net.evadeclient.addon). They show up in the menu with an Addon: <your mod> tag, in search, keybinds, profiles, .toggle and .set, and widgets appear in the HUD editor. Their settings are saved in Evade's config. This is separate from the Server API, which is for Minecraft servers.

Compile against the Evade jar without bundling it (for example modCompileOnly files("libs/evade-client.jar")), then list an entrypoint called evade in your fabric.mod.json:

"entrypoints": { "evade": ["com.example.MyEvadeAddon"] },
"suggests": { "evade": "*" }
public final class MyEvadeAddon implements EvadeAddon {
    @Override
    public void register(AddonRegistry registry) {
        registry.module(new Greeter());
        registry.hud(new SessionTimer());
    }
}

public final class Greeter extends AddonModule {
    final BooleanSetting loud = toggle("Loud", false, "Say it in capitals.");
    final NumberSetting times = slider("Times", 1, 1, 5, 1, "How many times to say it.");
    final ModeSetting style = mode("Style", "Friendly", "How it sounds.", "Friendly", "Formal");
    final ColorSetting tint = color("Tint", 0xFF3BE37A, "Colour of the greeting.");
    final KeySetting greetKey = key("Greet Key", GLFW.GLFW_KEY_UNKNOWN, "Hold to greet.");
    final StringSetting greeting = text("Greeting", "Hello", 32, "What it says.");

    public Greeter() { super("Greeter", "Says hello when you join a world.", AddonCategory.MISC); }

    @Override protected void onEnable() { /* ... */ }
}

public final class SessionTimer extends AddonTextHud {
    private final long start = System.currentTimeMillis();
    public SessionTimer() { super("Session Timer", "How long you've been playing.", 4, 60); }

    @Override protected List<String> lines(boolean preview) {
        return List.of("Session: " + (System.currentTimeMillis() - start) / 60000 + " min");
    }
}
  • Modules extend AddonModule and get the usual hooks: onTick, onRender, onHud, onEnable/onDisable and chat commands. They start off.
  • Widgets extend AddonTextHud (lines of text, styled like Evade's own) or AddonHudElement (draw anything; call size(w, h)). Both get Scale, Background, Hide In Menus and the other widget settings.
  • Settings: toggle, slider, mode, color, key and text. Keep module and setting names stable: saved values are keyed by them. A name that clashes with another module is refused.
  • Server rules apply. Servers can switch addon modules off with evade:rules by name, all of them with "@addons", or one mod's with "@addon:<modid>". Addons can't turn a module on past that. A module that throws an error is switched off.

Your addon is your responsibility. Evade can't review other mods' code, so it always shows which mod added each module. Please keep to Evade's own rules: nothing that shows what the game hides, and no automation of combat, movement or inventory. Servers may ban mods that do.
