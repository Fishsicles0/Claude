Servers

Made to be allowed.

Evade is quality of life only: no combat or movement cheats, no x-ray, no seeing through walls, nothing that plays for you and nothing that hides from anti-cheats. Here's where it's welcome, and how server owners stay in control.

Confirmed servers

Servers where Evade has been checked and is fine to use. More are added as owners confirm them.

  • EvadeCraft — the home of Evade. Every Evade mod is allowed.

Run a server where Evade is fine? Email us and we'll list it.

Always check a server's own rules too. A few very strict servers ban every modified client, however harmless.

What Evade does for you

  • Freelook switches itself off on servers known to forbid it, such as Hypixel.
  • AutoTip only ever runs on Hypixel, where /tip exists.
  • AutoGG waits a moment and never posts more than once every few seconds, so it can't spam.
  • AutoReconnect gives up after a few tries, waits longer each time, and never rejoins after a ban, a whitelist refusal, an AFK kick or a kick by an operator.
  • Camera Distance stops at 8 blocks, so the third-person camera can't be used to look over walls.
  • Minimap shows terrain only: never players, mobs, items, caves or anything underground. The one exception is the server's choice: team mates it shares through the Evade Server API, and only those already loaded near you.
  • Mods a server turns off show Disabled by this server in the menu and come back when you leave.

For server owners

The easy way: install the free Evade Server API plugin for Paper 1.21. Drop it in plugins/, restart, and choose which Evade mods to switch off in plugins/EvadeServerAPI/config.yml. Other plugins can use it to send waypoints, cooldowns, notifications and more. Everything below is what it does for you, if you'd rather send the messages yourself.

You can switch off any Evade mod for players on your server. Send a plugin message on the channel evade:rules after a player joins, with a UTF-8 JSON body:

{"disable": ["Freelook", "Minimap", "Fullbright"]}

Use the mod names exactly as they appear in Evade's menu (case doesn't matter). Evade turns those mods off straight away, stops players turning them back on while they're connected, and shows Disabled by this server on them. Send the message again to change the list, or {"disable": []} to allow everything. Nothing carries over to other servers.

Paper or Spigot example:

// onEnable(): getServer().getMessenger().registerOutgoingPluginChannel(this, "evade:rules");
byte[] body = "{\"disable\":[\"Freelook\"]}".getBytes(StandardCharsets.UTF_8);
player.sendPluginMessage(plugin, "evade:rules", body);

The full mod list, with every setting, is on the features page.

Evade Server API

Your server can also show things to Evade players: waypoints, cooldowns, notifications, titles, team markers, a custom border, light beams and holograms. Everything is purely visual, everything is your choice, and nothing shows more than a player could see for themselves: team markers and holograms need a clear line of sight, and nothing is ever drawn through walls. Players who don't run Evade simply ignore the messages.

evade:apiServer to client. A UTF-8 JSON body with no length prefix, like evade:rules: one message {"type": "...", ...}, or an array of up to 128 of them.
evade:helloClient to server. Sent once when the player joins, if your server has registered the channel, so you know Evade is there.

The hello looks like this. api only goes up for changes older servers would misread, and features lists the message families this version understands:

{"client": "evade", "version": "2.0.1", "api": 1,
 "features": ["waypoint", "cooldown", "notification", "title", "team", "border",
              "beam", "hologram", "rules", "settings", "discord"]}

The best moment to send your messages is when the hello arrives: by then the player is in the world and listening. Everything you sent is forgotten when the player leaves, or when your network moves them to another server, so send it again after each hello. Colours can be "#RRGGBB", "#AARRGGBB", a number or a name (red, orange, yellow, gold, green, lime, cyan, blue, purple, pink, white, gray, black). A dimension can be "overworld", "nether", "end" or a full id such as "minecraft:the_nether"; leave it out to show something in every dimension. Sending an add or set again with the same id replaces it.

waypoint.add / remove / clearWaypoints drawn like the player's own (box, beam, label, distance, Minimap), never saved and kept apart from theirs
cooldown.set / clearA timer with an item icon in the Cooldowns HUD
notificationA toast at the side of the screen
titleA large title and subtitle in Evade's style
team.set / clearMarkers above team mates the player can see, and dots on the Minimap
border.set / clearA rectangle drawn like the world border
beam.add / removeA coloured light beam, like a beacon's
hologram.add / removeFloating lines of text
rulesTurn mods off (as evade:rules) and limit settings for this session
discordStatus text for the player's Discord presence
resetForget everything this server has sent

Waypoints. beam defaults to on; color and dimension are optional. They show while the player has Waypoints on (it is by default), with their own label and beam settings. Remove one by id, or clear them all.

{"type": "waypoint.add", "id": "spawn", "name": "Spawn", "x": 0, "y": 64, "z": 0,
 "color": "#3BE37A", "dimension": "overworld", "beam": true}
{"type": "waypoint.remove", "id": "spawn"}
{"type": "waypoint.clear"}

Cooldowns. icon is any item id; seconds is the length, up to an hour, and 0 ends it. The timer runs on the player's side, so send it once. cooldown.clear without an id clears every cooldown you set.

{"type": "cooldown.set", "id": "dash", "name": "Dash", "icon": "minecraft:feather", "seconds": 8}
{"type": "cooldown.clear", "id": "dash"}

Notifications. level is info, success or warn; seconds defaults to 4 and stops at 15. At most four arrive every two seconds; any more are dropped.

{"type": "notification", "title": "Event", "text": "The arena opens in 1 minute",
 "seconds": 5, "level": "success"}

Titles. Times are in ticks, as in vanilla: fadeIn 10, stay 70 and fadeOut 20 unless you say otherwise. color is optional. A new title replaces the last; one with no title and no subtitle clears it.

{"type": "title", "title": "Round 2", "subtitle": "Fight!", "fadeIn": 10, "stay": 60, "fadeOut": 20}

Teams. A list of player UUIDs and a colour. A small marker floats above each listed player, but only while the player can actually see them: never through walls, never for invisible players, never further than 128 blocks. The Minimap shows them as dots only if they're already loaded near the player. Send several teams with different ids; team.clear without an id clears them all.

{"type": "team.set", "id": "red", "color": "red",
 "players": ["069a79f4-44e9-4726-a5be-fca90e38aaf5", "853c80ef-3c37-49fd-aa49-938b674adae6"]}
{"type": "team.clear", "id": "red"}

Border. Walls appear as the player comes within 48 blocks of an edge, like the world border. It's only a drawing: it doesn't stop anyone, so keep enforcing it on your side.

{"type": "border.set", "minX": -100, "minZ": -100, "maxX": 100, "maxZ": 100, "color": "#29D3F0"}
{"type": "border.clear"}

Beams. From the block up to the build limit, or height blocks. Terrain hides them like a beacon's beam. beam.remove without an id removes them all.

{"type": "beam.add", "id": "flag", "x": 120, "y": 70, "z": -40, "color": "gold", "height": 0}
{"type": "beam.remove", "id": "flag"}

Holograms. Up to eight lines (or one text) centred on the position, first line on top; § colour codes work. A hologram shows only within 48 blocks and while the player can see its spot, so place it in open air.

{"type": "hologram.add", "id": "shop", "x": 10.5, "y": 66, "z": 4.5,
 "lines": ["§6Shop", "Right-click the villager"]}
{"type": "hologram.remove", "id": "shop"}

Rules. disable works exactly like an evade:rules message. settings limits number settings for this session, by mod and setting name as in the menu: a number is the highest value allowed, or give min and max. The player's own values stay saved and come back when they leave. Each settings object replaces the last; leave either key out to keep what you set before.

{"type": "rules", "disable": ["Freelook"],
 "settings": {"Zoom": {"Max Zoom": 4}, "Camera Distance": {"Distance": {"min": 2, "max": 6}}}}

Discord. Status text, and an optional second line, for the player's Discord presence. Empty text clears it.

{"type": "discord", "text": "Playing Bedwars", "details": "Solo · Map: Lighthouse"}

Paper or Spigot example, showing a waypoint at spawn to every Evade player:

// onEnable()
getServer().getMessenger().registerOutgoingPluginChannel(this, "evade:api");
getServer().getMessenger().registerIncomingPluginChannel(this, "evade:hello", (channel, player, message) -> {
    // Evade is here and listening.
    String json = "{\"type\":\"waypoint.add\",\"id\":\"spawn\",\"name\":\"Spawn\","
            + "\"x\":0,\"y\":64,\"z\":0,\"color\":\"#3BE37A\"}";
    player.sendPluginMessage(this, "evade:api", json.getBytes(StandardCharsets.UTF_8));
});

Registering evade:hello as an incoming channel is what tells Evade it may say hello; without it Evade sends nothing. Use a JSON library such as Gson for anything bigger than this.

Report a problem

If an Evade mod causes trouble on your server, or you think one breaks your rules, email privacy@evadeclient.com with the server address and which mod. We'd rather fix it than have players caught out.
