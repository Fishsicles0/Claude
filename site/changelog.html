Every release, newest first. Each new mod ships with an automated in-game test where one is possible.

v0.5.0

Latest2026-11-20

35 new mods, a Misc category, waypoints and a test dummy. 123 mods in total.

Combat

AutoWeapon, Offhand, SelfTrap, HoleFiller, AutoWeb, BowSpam

Movement

NoSlow, InventoryMove, AirJump, ReverseStep, FastClimb, AutoJump

Player

FakePlayer, AutoReplenish, FastUse, MiddleClickExtra, AirPlace, AutoGap, ChestSwap

Visuals

Waypoints, HoleESP, Breadcrumbs, LogoutSpots, LightOverlay, NoRender, BetterTooltips, CameraClip

World

AutoBreed, AutoShearer, AutoSmelter, LiquidFiller

Misc (new category)

AutoReconnect, BetterChat, Notifier, AutoGG

  • New .waypoint command.
  • AntiBot leaves the FakePlayer dummy alone, so combat mods can be tried on it.
  • Fix: Time Changer no longer flickers back to the server's time for a moment when the server sends a time update.
  • Website: every mod's settings and defaults on the features page, plus these Docs and Changelog pages.

v0.4.0

2026-11-20

50 new mods, the Printer, and the optional Evade Texture Pack. 88 mods in total.

  • New mods include KillAura, CrystalAura, AnchorAura, Velocity, Fly, Speed, Scaffold, NoFall, ESP, Freecam, Nametags, Nuker, AutoFarm and the Inventory Viewer HUD.
  • Printer: builds Litematica placements, or loads .litematic files itself. New schematics folder.
  • Movement, World and Player categories in the menu.
  • Evade Texture Pack 1.0, a separate optional download.
  • Installer 1.0.1 creates the schematics folder.
  • Website redesign.

v0.3.1

2026-11-20

New logo and wordmark, the Evade Installer, and evadeclient.com.

  • One-click installer for Windows (.exe) and macOS/Linux (.jar), with checksums for every download.
  • New Evade logo across the client and the website.

Earlier builds

  • Combat: AutoPot, AutoTotem, AutoMend, AimAssist, AutoCritical, AutoClicker, Reach, TriggerBot, Hitbox.
