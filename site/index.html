Install

Up and running in two minutes.

Download the installer

The .exe on Windows. On Mac and Linux, use the .jar installer (needs Java 17+).

Click Install

It sets up Fabric, Fabric API and Evade in their own folder, so your normal mods and worlds aren't touched.

Open the launcher

In the Minecraft Launcher, pick Evade Client next to the Play button.

Play

Join a world and press Right Shift to open the menu. Run the installer again any time to update.

Prefer doing it by hand? Put the mod jar and Fabric API in your mods folder with Fabric Loader for 1.21.11.

FAQ

Questions.

Is it free?

Yes. Evade is completely free, with no account or license key.

Which versions does it support?

Minecraft Java 1.21.11. The installer sets up the right Fabric Loader and Fabric API for you. Other versions aren't supported yet.

Can I get banned?

Yes, on most servers. Combat modules like Reach, TriggerBot and AutoClicker break the rules of most multiplayer servers and anti-cheats look for them. Use those in singleplayer, on your own server, or on servers that allow clients. The HUD and quality-of-life mods (Keystrokes, Zoom, ToggleSprint and so on) are the same kind of thing other PvP clients offer.

Does it work with Sodium, Iris and other mods?

It's a normal Fabric mod, so it runs alongside most others. If something conflicts, remove mods one at a time to find which one.

Windows says "Windows protected your PC"

That appears for new apps that aren't code-signed yet. Click More info, then Run anyway. The installer only writes to your .minecraft folder.

How do I update?

Run the installer again. It shows Update Evade Client when a new version is out and replaces the old files.

Where are my settings saved?

In .minecraft/evade/config/evade/config.json if you used the installer. Back up that file to keep your layout and keybinds.

Is it safe?

The installer only touches your .minecraft folder: it adds an evade folder, one version file and one launcher profile, and backs up your launcher settings first. Every download is checked against a SHA-256 or SHA-512 checksum before it's used.
