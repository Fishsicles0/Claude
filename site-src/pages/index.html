Install

Two minutes to set up.

The installer does the work and keeps your normal Minecraft untouched.

Download

The .exe on Windows, the .jar on macOS and Linux.

Click Install

Sets up Fabric, Fabric API and Evade in their own folder.

Pick the profile

Choose Evade Client in the Minecraft Launcher.

Play

Press Right Shift in game to open the menu.
