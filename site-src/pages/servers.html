Servers

Made to be allowed.

Evade is quality of life only: no combat or movement cheats, no x-ray, no seeing through walls, nothing that plays for you and nothing that hides from anti-cheats. Here's where it's welcome, and how server owners stay in control.

Confirmed servers

Servers where Evade has been checked and is fine to use. More are added as owners confirm them.

  • EvadeCraft — the home of Evade. Every Evade mod is allowed.

Run a server where Evade is fine? Email us and we'll list it.

Always check a server's own rules too. A few very strict servers ban every modified client, however harmless.

What Evade does for you

  • Freelook switches itself off on servers known to forbid it, such as Hypixel.
  • AutoTip only ever runs on Hypixel, where /tip exists.
  • AutoGG waits a moment and never posts more than once every few seconds, so it can't spam.
  • AutoReconnect gives up after a few tries, waits longer each time, and never rejoins after a ban, a whitelist refusal, an AFK kick or a kick by an operator.
  • Camera Distance stops at 8 blocks, so the third-person camera can't be used to look over walls.
  • Minimap shows terrain only: never players, mobs, items, caves or anything underground.
  • Mods a server turns off show Disabled by this server in the menu and come back when you leave.

For server owners

You can switch off any Evade mod for players on your server. Send a plugin message on the channel evade:rules after a player joins, with a UTF-8 JSON body:

{"disable": ["Freelook", "Minimap", "Fullbright"]}

Use the mod names exactly as they appear in Evade's menu (case doesn't matter). Evade turns those mods off straight away, stops players turning them back on while they're connected, and shows Disabled by this server on them. Send the message again to change the list, or {"disable": []} to allow everything. Nothing carries over to other servers.

Paper or Spigot example:

// onEnable(): getServer().getMessenger().registerOutgoingPluginChannel(this, "evade:rules");
byte[] body = "{\"disable\":[\"Freelook\"]}".getBytes(StandardCharsets.UTF_8);
player.sendPluginMessage(plugin, "evade:rules", body);

The full mod list, with every setting, is on the features page.

Report a problem

If an Evade mod causes trouble on your server, or you think one breaks your rules, email privacy@evadeclient.com with the server address and which mod. We'd rather fix it than have players caught out.
