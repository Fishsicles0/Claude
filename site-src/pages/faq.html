General

Is it free?

Yes. Evade is completely free, with no account or license key.

Is it allowed on servers?

Yes, on the great majority. Evade is a quality-of-life client, like Lunar or Badlion: a HUD, zoom, freelook, a custom crosshair, waypoints and visual tweaks. There are no combat or movement cheats, no ESP or x-ray, and nothing that automates gameplay or hides from anti-cheats. Those are the same kinds of features big servers (Hypixel and others) allow. A few very strict servers ban any modified client at all, so always check the server's own rules — but you won't be using anything that's against the spirit of fair play.

Which versions does it support?

Minecraft Java {{MC}} with Fabric. The installer sets up the right Fabric Loader and Fabric API for you. Other versions aren't supported yet.

What's new in v{{VERSION}}?

This is the first release of Evade as a server-safe quality-of-life client: every combat and movement cheat was removed, leaving {{TOTAL}} QoL mods — the full HUD (now with Stopwatch, Saturation, Item Counter and PvP Info), zoom, freelook, waypoints, the three menu styles and the Evade Texture Pack. See the changelog and the docs.

Does it work with Sodium, Iris and other mods?

It's a normal Fabric mod, so it should run alongside most others, but compatibility with Sodium, Iris and Lithium hasn't been tested yet. Put extra mods in .minecraft/evade/mods. If something conflicts, remove mods one at a time to find which one.

Is there a Bedrock or Xbox version?

No, and it isn't possible. Evade is a Java Edition Fabric mod. Bedrock (Xbox, PlayStation, Switch, mobile, Windows 10/11) is a closed platform — you can't install a custom client or mod on a console at all. Anything that claims to add a "client" to a console actually routes your connection through a proxy that rewrites your packets, which is both a different kind of software and squarely in cheating territory. We won't build that. If you only need a console to join a server it can't normally reach, look at BedrockConnect — a separate, open-source connectivity tool.

How does it compare to Lunar or Badlion?

It's the same idea: a free, server-safe client that adds a HUD, zoom, cosmetics-style tweaks and quality-of-life mods on top of vanilla. Evade is a Fabric mod, so it runs alongside Sodium, Iris and other Fabric mods, and it's open about being just quality of life — no cheats, no "undetected" claims.

Why isn't there an FPS boost or shaders?

Those need a different renderer. Install Sodium (FPS) or Iris (shaders) alongside Evade instead. Evade doesn't bundle other people's mods, including OptiFine.

Installing & updating

Windows says "Windows protected your PC"

That appears for new apps that aren't code-signed yet. Click More info, then Run anyway. The installer only writes to your .minecraft folder.

The Mac or Linux installer won't open

The .jar installer needs Java 17 or newer. Install it from adoptium.net, then double-click the jar, or run java -jar EvadeInstaller.jar.

How do I update?

Run the installer again. It shows Update Evade Client when a new version is out and replaces the old files. Your settings are kept.

I don't see "Evade Client" in the launcher

Close and reopen the Minecraft Launcher after installing. If you picked a different Minecraft folder in the installer, make sure it's the one your launcher uses.

How do I uninstall it?

Delete the evade folder and versions/evade-client-{{MC}} inside .minecraft, then remove the Evade Client installation in the launcher.

Texture Pack

Does the texture pack come with the client?

No. It's an optional, separate download on the download page. The client and installer never add it.

What does it change?

Menus, buttons, sliders, tooltips, the hotbar and crosshair turn black and red. It also lowers fire on your screen, makes diamond and netherite sword blades and ender pearls red, and puts the Evade logo on the title screen. It's made from Minecraft's own textures, recoloured.

How do I install it?

In Minecraft go to Options, Resource Packs, Open Pack Folder, put the zip in that folder, then move the pack to the right-hand list. It's made for Minecraft {{MC}} and works with or without Evade.

Safety & settings

Is it safe to install?

The installer only touches your .minecraft folder: it adds an evade folder, one version file and one launcher profile, and backs up your launcher settings first. Every download is checked against a SHA-256 or SHA-512 checksum before it's used. The checksums are listed on the download page.

Where are my settings saved?

In .minecraft/evade/config/evade/config.json if you used the installer. Back up that file to keep your layout and keybinds.

Still stuck? Reinstalling with the latest installer fixes most problems.
