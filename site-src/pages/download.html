Bedrock / console

Not a client

Bedrock (Xbox, PlayStation, Switch, mobile, Windows 10/11) is a locked platform — you can't install a custom client there, so Evade is Java only. We won't ship a fake Bedrock download. If you just need a console to reach a server it can't normally, that's BedrockConnect, a separate open-source connectivity tool — not a client, and nothing to do with cheating.

Evade Launcher

Press Play and it updates Evade if needed, then opens the Minecraft Launcher with Evade selected. Sign-in stays with the Minecraft Launcher and your Microsoft account: the Evade Launcher never sees your password. Make separate instances (each with its own mods, settings and worlds), switch mods on and off, and add more from Modrinth. Evade keeps its own folder, so your normal game isn't touched. It can also add these, each downloaded straight from Modrinth:

  • FPS mods (on by default) for a big frame-rate boost: Sodium, Lithium, FerriteCore, ImmediatelyFast, EntityCulling, MoreCulling (with its library, Cloth Config), Krypton, BadOptimizations and Sodium Extra.
  • Faster menus (part of FPS mods): Fast IP Ping for a quicker server list and FastQuit for instant world quitting.
  • Voice chat (on by default): Simple Voice Chat by henkelmax, so voice works on the many servers that use it.
  • Shaders (off by default): Iris with the Photon shader pack by SixthSurge, plus the lighter Complementary Reimagined.

Install guide

Up and running in two minutes.

Download the launcher

The .exe on Windows. On macOS and Linux use the .jar, which needs Java 17+.

Click Install

The first time, it sets up Fabric, Fabric API, Evade and (if you leave them on) the FPS mods and voice chat in their own folder.

Press Play

The Minecraft Launcher opens with Evade Client selected. Press its Play button (sign in once if it asks).

Right Shift

Join a world and press Right Shift to open the menu.
